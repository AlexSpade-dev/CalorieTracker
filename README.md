# CalorieTracker
Title: "CalorieTrack+: Integrated Health Monitoring System for Students Using Image Recognition and Database Tracking”

Description: CalorieTrack+ is a student-centered web application designed to help students monitor and improve their health habits. The app allows users to log meals through manual entry, barcode scanning, or image scanning (photo of food) to estimate calories, and for cooked meals it supports ingredient-based calorie estimation for realistic results. The system provides daily summaries and progress charts to help students maintain healthy eating habits, and more features can be added such as gym/workout tracking, sleep tracking, daily health summaries, and weekly reports, making CalorieTrack+ a complete health monitoring tool for students.
